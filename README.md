# id

This is a javascript npm package that generates general purpose unique hash/ids.

## Installation

```bash
npm i @pr4j3sh/id
```

## Usage

- CJS

```bash
const id = require("@pr4j3sh/id");

console.log(id());
```

- MJS

```bash

import id from "@pr4j3sh/id";

console.log(id());
```
